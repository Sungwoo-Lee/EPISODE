What the trained agents do, and which settings move it

A standard first look at a trained population: how much of its time each agent spends on five behaviours, how long it survives, and which features of the world and which training settings push each behaviour up or down. {{STATUS_LINE}}

PURPOSE

After training, every agent in a study is replayed for about a million evaluation episodes and every step is recorded. This page summarises those recordings the same way for every population, so that two studies can be read side by side. It measures five behaviours, each as a share of the steps the agent chose in an episode: hiding in a bush, eating, being within two squares of a rabbit, being within two squares of a predator, and, in worlds with temperature, standing on a warm square. It also reports survival, measured in steps, which is how this project judges performance.

The page then asks which features of each episode (how many predators, how injured the agent started, how predator-like a rabbit smells, how cold the world is) go with more or less of each behaviour, run by run; and, across runs, which settings — the smell world, the agent type, the training seed — move each behaviour most. That last part is exploratory screening to help choose a training direction. It is not a test of any study's pre-registered question, and it draws no conclusions: interpretation is written separately.

01 Behaviours and survival, per run

One marker per training run. Colour is the smell world, marker shape is the agent type, and runs of the same world and agent sit side by side, one per training seed. The same encoding is used on every figure of this page.

What this figure cannot tell you

Why a run behaves as it does. A higher share of hiding can come from more danger in the episodes it happened to meet, or from a different strategy; the next figures separate those. Differences between seeds of the same setting show how much training alone varies.

05 Which settings move each behaviour — {{TARGET_LABEL}}

Exploratory screening

This figure ranks settings to help choose a training direction. It is not the smell study's pre-registered verdict, which lives in that study; its smell panels carry no test and no interval.

What this figure cannot tell you

Whether a setting truly matters: with three seeds per setting, intervals are wide and the ranking is a screen, not a result. Nor does it answer the smell study's question about rabbit smell and injury; that study's registered reading does.

06 The behaviour by the agent's state, the rabbit's smell and nearby animals — {{TARGET_LABEL}}

What this figure cannot tell you
