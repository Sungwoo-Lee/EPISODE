07 Experiment tests: bush time in controlled scenes with a pond

Exploratory

This section is not part of the thirst study's pre-registered read-outs. It shows how each agent behaves in twelve small, fixed test scenes at every checkpoint saved during training. With one training run per world and agent, it describes those runs; it does not compare agents or worlds. {{W_F7_BUDGET}}

Each scene is built on the trained world itself: its own map size, smell reach, pond size, body and temperature system. Only the layout is fixed: the agent starts at the same square, a hiding bush sits three squares to its west with a campfire beside it, and a pond sits three squares diagonally south-east, at the same distance at every map size. Six animal setups — no animal, a hunting predator, a harmless chasing rabbit, the chasing rabbit with its predator-like smell channel removed, a harmless wandering rabbit, and a wandering rabbit that smells like a predator — are each run with the agent unhurt (injury 0) and badly injured (injury 70 of 100), 30 episodes of 100 steps per checkpoint. Every episode starts at hydration {{W_CALIB_S}}. An agent that walks to the pond is no longer showing how much it hides, so bush time is read in each episode only up to its first step onto the pond, and the share of episodes that reached the pond is drawn beside it.

What this section cannot tell you

Whether one agent or one world hides more than another: each has a single training run, and the intervals describe that run only. Nor what an agent would do in a scene without a pond.
