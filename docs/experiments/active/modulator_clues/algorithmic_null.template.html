What Both Agents Compute

For a month the agent with a neuromodulator and the agent without one have come out almost identical in every world we built. Before designing a better modulator, this page asks what computation the two agents share, and only then why the modulator adds nothing to it.

PURPOSEWhy this page exists

The long-term goal is to find a neuromodulator that actually helps an agent. Across a month of comparisons in many different worlds, the modulated and ordinary agents have come out almost the same every time. That consistency is too tight to be noise: it points to both architectures converging on the same way of processing information, shaped more by the structure of the world than by the network design. So it is not enough to treat the result as a failed hypothesis and try another modulator at random. A modulator can only help by adding something the network does not already compute, and right now we do not know what that shared computation is.

The two questions, in this order

First: what computation does every architecture converge on in these worlds?

Then: why does the modulator not help?

This page collects the evidence behind that reordering, the algorithmic explanations a review of the literature turned up, and the measurements planned to answer both questions. No new analysis has been run yet. The planned sections below say what will be measured, on which data, and what each outcome would mean. Most of them wait on a training run that started on 2026-09-29.

01A month of near-identical results

About 200 training runs compared the two agents. The ordinary agent is a recurrent network trained with PPO. The modulated agent is the same network plus a small side network, the neuromodulator, which at every step sends each unit in up to four places of the main network a gain (a multiplier) and an offset (an added amount). Performance is always measured in survival steps: how long the agent stays alive.

What the pattern says

If a real but modest difference were hidden by noise, the gaps between independently trained agents would scatter: sometimes clearly positive, sometimes clearly negative, about as far apart as two ordinary agents with different seeds. They do not scatter. They stay pinned near zero across worlds that differ a great deal, and in the 16-world factorial the gap has the same sign every time. That is the signature of something systematic making the two agents come out the same.

02Four candidate reasons the agents come out the same

A review of this project's runs, code and the FiLM and reinforcement-learning literature it holds produced four explanations. They are not exclusive. Each is a claim the planned measurements can test.

1. The two agents start from the same place

The main network's layers are built before the modulator (in src/models/recurrent_ppo_network.py, the encoder at line 400, the actor and critic at lines 424–429, the modulator at line 458), and the ordering is kept deliberately so the random-number stream is unchanged. With the same seed, the modulated agent's main network therefore starts with exactly the ordinary agent's weights and sees the same stream of environments. The modulator's gain starts near 1 (1 ± 0.3) and its offset near 0, so at the start it barely changes anything. Small, clipped PPO updates can then keep both runs in the same solution.

2. The worlds ask for threshold shifts, which an ordinary network already has

Internal states (hunger, injury, temperature) do act as task variables here: the reward is the change in homeostatic drive, so what counts as rewarding depends on the agent's needs, in the sense of Keramati and Gutkin{{CITE:keramati}}. But the kind of task family matters. An ordinary network receives the internal state as an input, and that adds a context-dependent amount to each unit:

← wider than the screen — scroll it sideways; the right-hand end is cut off

ordinary:   h = ReLU( W_x·x + W_c·c + b )
FiLM:       h = ReLU( γ(c)·(W_x·x + b) + β(c) )

With the gain γ fixed at 1 the two are the same: feeding the condition in as an input is FiLM without the gain{{CITE:perez}}. An added amount moves the point at which a unit switches on, which is a threshold shift (a hungrier agent approaches fainter food, an injured one hides sooner). The gain does something different: it changes how strongly a sense drives a unit, which is what is needed when a need must change which senses matter. The behaviour measured in ordinary agents so far looks mostly like threshold shifts. The ordinary agent's memory is also a GRU, whose gates already multiply its state by functions of its inputs, internal state included.

Three more properties make these worlds easy for an ordinary network. The needs rise and fall many times within every episode, so every training batch contains every context and there is no interference between them to relieve. The internal state is visible at every step, so there is no hidden context to infer. And the published cases where FiLM beats a plain network all involve a regime that changes which behaviour is correct, such as a task switch or a hidden context. The one large positive result here came from the May probe, whose predator alternated between dangerous and harmless phases.

3. Training gives the modulator no reason to carry context, and it wakes up late

One optimiser updates every parameter, modulator included, with the same learning rate (gradient clip 0.5, then Adam at 5×10−4), no weight decay and no objective of its own. The critic's error also trains the modulator. The main network is roughly 100 times larger and absorbs the body-related part of the learning signal first. Two measured facts fit this. Only about 15% of the modulator's gain variation follows the situation; the rest is a fixed per-unit setting the main network could have learned itself. And its share of the gradient grows over training, reaching 40–75% in some arms only by the end. A part that starts working only in the second half of training can shape the final solution but cannot shorten the early climb, where a faster-learning advantage would appear.

4. The measurements could not see the kind of gain FiLM usually gives

Every comparison so far used final performance. In reinforcement learning, FiLM's reported advantage is mostly faster learning, and learning speed has not been measured here with seeds.

A puzzle any explanation has to fit

Freezing a trained modulated agent's modulation at its own average costs it 47 to 180 of about 200 survival steps (measured on modulators reading every sense, and not at every site). Yet the modulated agent trained end to end does no better than an ordinary one. The reading that fits both: training routes part of the same solution through the modulator, so freezing it removes a working part, not a benefit.

03Question 1: what do the two agents compute?

If the two agents converge on the same information processing, the evidence should show it at the level of their internal activity, not only their scores. Two measures, both run on identical inputs: one stored episode is fed to both agents, with their memory reset at the first step, so every activation is paired with the other agent's activation at the same moment.

A1

Layer similarity (CKA)

Needs tooling

Centred kernel alignment{{CITE:kornblith}} asks whether two layers arrange the same set of inputs in the same way: whether inputs that look alike to one agent's layer also look alike to the other's. It compares layers of different networks without needing their units to line up.

Layers
Encoder output, memory state, memory output, actor and critic hidden layers; for the modulated agent both before and after the gain and offset are applied.
Caution
Linear CKA ignores rotations and uniform scaling but not per-unit rescaling, which is exactly what the modulator's large fixed gain does. It is paired with a rescaling-robust measure (SVCCA{{CITE:raghu}}, or how well one agent's layer linearly predicts the other's).
Reads as
High similarity beyond the seed yardstick (A3): the agents represent the world the same way. High only within the same seed: inherited from the shared start.
Planned figure. A layer-by-layer similarity matrix, modulated against ordinary, beside the ordinary-against-ordinary matrix for different seeds.
A2

Decoding profiles

Needs tooling

A small linear readout is trained to recover a quantity from each layer. How well it succeeds, layer by layer, is that agent's decoding profile.

Quantities
Hunger (satiation), injury (injury_level), distance to the nearest predator, and value, measured as survival steps remaining in the episode.
Caution
Readouts are trained and tested on different episodes, never on different steps of the same episode, because neighbouring steps are nearly identical and a step-level split inflates every score.
Reads as
Matching profiles: the same information is present in the same places. A mismatch shows where the modulated agent holds information differently.
Planned figure. Decoding accuracy for each quantity across layers, one line per agent, with the seed-to-seed range shaded.

A4

Across worlds

Waiting on training

How far each agent's processing moves between worlds, and whether the two agents move together. If both change a great deal from world to world while staying close to each other, their shared processing tracks the world rather than the architecture.

Data
The May replication's stages, which are different worlds. The level-05 factorial has 16 worlds but every pair there shares seed 42, so it cannot separate the two explanations on its own.

04Question 2: why does the modulator not help?

These test the first and third candidate reasons directly. They come second because their results are easier to read once Question 1 has said what the two agents share.

B1

Break the shared start

Needs a decision

Two ways to stop the modulated agent from beginning as a copy of the ordinary one.

  • Train modulated agents whose main network starts from a different seed than their paired ordinary agent.
  • Or keep the same seed but give the modulator a stronger start: output heads initialised to zero so the gain is exactly 1 and the offset exactly 0, plus a learning rate of its own so its early updates are not swamped.
Reads as
If the gaps then scatter at the size of ordinary seed-to-seed differences, the shared start produced the identical results. If they stay pinned near zero, the equivalence is real.
B2

When the modulator wakes up

Needs tooling

Four measures of when the modulator starts to matter during training, because each can mislead on its own:

MeasureWhat it answers
Share of the gradient reaching the modulator, split by loss termHow much of the learning signal it receives
Size of its weight updates relative to its weights, against the main network'sHow fast it actually changes (Adam rescales gradients, so the share alone can mislead)
How much its output varies with the situation, at each checkpointWhen its output starts responding
Cost of freezing it, at a subset of checkpointsWhen it becomes something the network relies on
Summary
Wake-up lag: the checkpoint at which a measure reaches half its final value, minus the checkpoint at which survival reaches 90% of its final value. A positive lag means the modulator wakes after learning has levelled off, so it cannot speed learning up.
Also
The success test for B1's stronger start: it should pull the wake-up earlier. If the lag shrinks but learning speed does not change, late wake-up was not the cause.

05Where things stand

Established

  • No modulated-vs-ordinary difference beyond seed noise in about 200 runs.
  • The gaps are pinned near zero across very different worlds, not scattered.
  • The modulator is active and relied on inside a trained agent.
  • Both agents start from the same main-network weights under the same seed.
  • The modulator has no training signal or learning rate of its own.

Open

  • Whether the two agents compute the same thing internally (A1–A4).
  • Whether the shared start explains the identical results (B1).
  • When the modulator begins to matter during training (B2).
  • Whether the modulator learns faster than it performs; learning speed is unmeasured.

Discussed, not yet planned

  • Train a plain network to imitate a modulated agent's recorded behaviour: if the copy matches it, the modulator added nothing a plain network cannot represent.
  • Re-read existing runs for learning speed: area under the learning curve and time to a threshold.
  • Controls never run: the same freeze applied to an ordinary agent; how many units are permanently switched off; whether the modulator's varying gain follows the agent's internal state.
  • A world-conflict measure: how often identical external situations call for different actions depending on internal state.
  • Give the modulator its own training signal, such as predicting changes in the body.
  • A two-by-two design: internal-state signals hidden from the main network or visible to it, crossed with a stable or an alternating world.
