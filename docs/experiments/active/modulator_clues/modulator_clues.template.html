Where Does the Modulator Matter?

A survey, not a verdict. The same analyses the project has used before, re-run on an ordinary agent and a neuromodulated one across three versions of the world, to collect clues about when, how and why the modulator makes a difference — and so where to look next.

01 What this page is

The project's goal is an agent whose behaviour genuinely depends on the state of its own body — how hurt, how hungry, how cold it is. One route there is a neuromodulator: a small network that rescales the signals flowing through the rest of the agent's brain (the FiLM style; a hypernetwork is the heavier alternative). In the runs compared here it reads every input the agent receives — its internal signals and its senses alike — so it is free to key its rescaling on the body, on the outside world, or on both. Two agents were trained side by side in every world: an ordinary one, and one with the modulator acting at all four places it can act — the two sensory encoders, the memory, and the decision heads.

This page does not ask whether the modulator works. With one training run per agent per world, it could not answer that. It asks where the two agents differ, where they do not, and what changes each time the world was changed — so the next experiment can be aimed. Every figure therefore leads with the gap: the neuromodulated agent's value minus the ordinary agent's.

How to read every figure

Blue is the ordinary agent, orange the neuromodulated one, black the gap between them. A badge above each caption says what kind of evidence it is: causal (the agent's starting injury was assigned at random, so behaviour that tracks it was caused by it), observational (what goes together in the agent's own history), or a controlled test scene. Where a spread is drawn it is how much ONE training run moves between its late checkpoints — never how much two runs differ, which nothing here can measure.

The same analyses were published for the Sensor Ladder and for "What makes this agent hide?", and the page follows their order, then adds a look inside the modulator, controlled test scenes, and two threads specific to the thermal levels. It ends with every gap in one table and the leads it suggests.

Both were built so that behaviour should need to depend on internal state — so they are where a modulator effect ought to be most likely.

Some cells are empty for reasons worth stating. Level 02 never hands out a random starting injury, so no causal injury measure exists there. Body temperature is never randomised either — every episode starts at the target — so every body-temperature result is observational. The blind world has no test scenes, and its saved configuration no longer loads under the current schema, so it has no late-checkpoint data. Wave 1's test scenes with animals in them predate a fix to the hiding bush and are not used.

Read together with the figures, the page offers these leads — each a direction to explore, not a result:

  1. The environment moves state dependence far more than the modulator does. Making cover heal roughly quadrupled a wound's pull on hiding (Figure 4), and the modulator shifted it little in any world (Figures 2 and 4). A modulator may need a task where the right action reverses with internal state rather than just strengthening — otherwise the ordinary network, which also sees its internal state, can learn the same thing.
  2. Test what the modulator keys on. It reads every input, so its small extra weight on predator smell (Figure 5) is what its inputs allow, not evidence of state dependence. The direct test is an arm whose modulator reads the internal signals only — the project's existing site-by-input grid already has that slice for the blind world.
  3. Most of the modulator's output is a constant. Only 8–31% of its gain variation changes from moment to moment (Figure 6), and less at the thermal levels. Worth measuring what that part follows, and trying a design that cannot collapse into a fixed rescaling — a hypernetwork, or a penalty on the constant part.
  4. At Wave 1's thermal levels the modulated agent's threat response depended more on injury (Figure 2) — the only pattern on the page that holds its sign across all five late checkpoints, at the levels designed to need it. It did not recur in Wave 2, where cover heals and injury matters more for everyone. Worth asking whether the modulator's effect appears only while injury is a weaker cue, and replicating Wave 1 levels 05/06 with more seeds.
  5. Level 06's noise changes the wound's pull in both agents (Figure 10), in the same direction in both waves and inside one run's checkpoint spread. Whether the modulated agent adjusts more needs a seeded replication of levels 05 and 06.
  6. In a scene with nothing to do, the two agents idle differently (Figure 7) — mainly because the ordinary agent's idle hiding swings from checkpoint to checkpoint. A lead about default behaviour and its stability, not about state dependence.

14 What this page cannot say

The binding limit

One training run per agent per world. Every gap on this page is one run against one run. Spreads are how much a single run moves between its late checkpoints, not how far two runs of the same configuration would land apart, and nothing here can measure the latter. That is why the page ranks leads rather than declaring effects.

  • Successive worlds change several things at once. Blind to Wave 1 added vision and made the bush predator-proof; Wave 1 to Wave 2 changed healing, the fullness target and over-eating. No difference between worlds can be pinned on one of those changes.
  • Most figures read only the final checkpoint, because the filtered analyses need the full million-episode sample. The coarse measures in Figure 2 carry a late-checkpoint spread, and a check showed a hundred thousand episodes reproduce them within a third of a point.
  • Wave 2 levels 02 and 03 were still training and are left out; Wave 1 levels 02 and 03 are compared at matched training length.

A separate page, The Last Checkpoint Lies, explains the measurement rules this page follows and the earlier readings they replaced.
