Results · neuromodulator vs unmodulated

Looking Inside the Modulator

Agents built with a neuromodulator do not behave measurably differently from agents built without one. So is the modulator doing anything at all? Three analyses, run on already-trained agents with no retraining, say yes — and say what.

Written for a reader who has not seen this project before. Every term is explained where it first appears. Updated 2026-09-09; the page previously listed these three as work to be done and now carries their results.

What the thing under test actually is

The agent lives in a small grid world and has to stay alive — find food, avoid predators, heal. Its main network turns what it senses into an action.

Alongside it sits a second, much smaller network: the neuromodulator. It reads the same senses and, at every timestep, nudges the main network's internal signals. The nudge is plain arithmetic. For each internal unit of the main network, the modulator emits two numbers:

adjusted value = gain × original value + offset

A gain of 1 and an offset of 0 leaves the unit untouched. A gain of 0.3 turns it down; a negative gain flips its sign. In the literature this scheme is called FiLM, and the two numbers are usually written γ (gain) and β (offset). This page says gain and offset.

Because the modulator recomputes them at every timestep from what the agent currently senses, they are a running signal, not fixed settings — which is the whole point, and the thing these analyses test.

The modulator can be pointed at four places in the main network, called sites:

encoder
where raw senses are first processed
rnn
the memory cell, which carries information between timesteps
actor
the layer that chooses the action
critic
the layer that estimates how good the current situation is

Two more terms used throughout. A checkpoint is a snapshot of the network's weights saved during training — there are 50 per run, so a checkpoint series shows how something changed as the agent learned. And survival steps is how long the agent stays alive, which is the only performance measure this project uses; it never scores agents on accumulated reward.

Thirty-two trained agents were available: sixteen configurations, run under two different training recipes. One agent per configuration — which constrains what can be concluded, and is flagged wherever it bites.

Headline

The modulator's moment-to-moment variation is doing real work. Replay a trained agent with its modulation held fixed at its own average — still adjusting the network, but identically in every situation — and it loses 47–180 survival steps out of about 200, with the outcome changing in 33–84% of episodes.

That was not the expected answer. Two analyses in, the evidence pointed at a modulator that had settled into a fixed re-tuning the main network could have learned by itself: only 15% of its variation turned out to respond to context at all. That 15% is nonetheless load-bearing.

Why the modulator's average does not count

One idea runs underneath both of the later analyses, and it is worth a minute because it changes what the numbers are allowed to mean.

A gauge quantity is a number in a description that you can change freely without changing anything you could observe. It is a feature of the bookkeeping, not of the world. The idea is old and the standard examples are worth having in mind before meeting it inside a network.

Textbook example 1 · height

Measure a building from sea level, or from its own ground floor. Every number changes. Nothing you could check with a tape measure does.

Zero pointrooffirst floorroof − first floor

the ground floor75 m0 m75 m

The last column is the only one anybody can measure, and it is identical. The choice of zero is a gauge: real in the description, absent from the building.

Textbook example 2 · voltage

The canonical case from physics, and the one that makes the idea feel less like a technicality. A bird perches on a 400,000-volt power line and is unharmed. Its feet are at 400,000 volts — an enormous number — but both feet are at the same enormous number, and only the difference across the bird can do anything to it.

Four columns — scroll the table sideways to reach the last one.

Two descriptions of exactly the same bird on exactly the same wire. The absolute voltages differ by 400,000; every measurable quantity is unchanged. Physicists say you may add any constant to every voltage in a circuit and nothing observable moves — that freedom is the gauge.

Both examples share one shape, and it gives a test you can apply to anything: change the number, and ask whether any measurement changes. If none does, the number was gauge — it was telling you about your own choice of description, not about the thing being described.

The trap is that gauge quantities look like ordinary facts. "The roof is at 120 metres" and "the bird is at 400,000 volts" are perfectly sensible sentences. They are just not sentences about the roof or the bird alone; they are half about where somebody decided to put zero. Averaging them, comparing them between buildings, or watching them drift over time will all produce numbers that mean less than they appear to.

The modulator's average gain and average offset are gauge quantities in exactly this sense. The difference is that here the freedom is not "add a constant to every reading" but "move a multiplication from one place to another". Here it is, as arithmetic. Suppose the modulator emitted a fixed gain and offset — the same values in every situation. The layer it adjusts would compute:

With a modulator, emitting a constant

input →layer W, bias b →× gain, + offset →ReLU →output

computes exactly the same function as

No modulator at all, weights rescaled once

input →layer gain×W, bias gain×b+offset →ReLU →output

Schematic, not a measurement — it shows an algebraic identity, not data. The two highlighted boxes are deliberately the same colour: they are the same arithmetic in two places, which is the whole point. Multiplying a layer's output by a constant is the same as having scaled that layer's weights by the constant in the first place; adding a constant afterwards is the same as having shifted its bias.

So a modulator that emits a fixed value is doing nothing the network could not have done by itself. Training could have found the rescaled weights directly. The constant part of the modulation is invisible from outside the network.

Three consequences, all of which shaped these analyses:

  • A mean gain of 0.35 tells you nothing on its own. It looks like heavy suppression, but the layer's own weights may simply be larger to compensate. Comparing average gains between two agents compares their bookkeeping, not their behaviour.
  • "Have the averages settled?" is not a real question. Because moving along this direction changes nothing, there is no pressure pushing it anywhere — the loss is flat along it. With no term penalising large weights, the averages simply drift for as long as you keep training. An earlier version of this project's training audit treated that drift as unfinished learning; it isn't.
  • Only the variation is observable. The part of the signal that changes with the situation cannot be folded into fixed weights, because fixed weights cannot change. That is the entire reason analysis 02 measures the varying share and analysis 03 destroys it deliberately.

One thing the gauge argument does not excuse

The rescaling above is exact only for what the layer computes before the ReLU. ReLU passes positive values and blocks negative ones — so where a unit sits relative to zero is not a bookkeeping choice, it is a fact about the network.

If the gain and offset together push a unit below zero in every situation, that unit outputs nothing, ever. And because it outputs nothing, the learning process gets no signal about it, so it cannot recover — it is stuck. That is a genuine failure mode hiding underneath a set of numbers the gauge argument otherwise tells us to ignore, and nothing currently recorded distinguishes it from a harmless turning-down. It is the top item in the still-open list below.

The three analyses

01

Could the modulator matter at all?

done

Method, in plain terms. Read the modulator's learned weights and work out arithmetically the widest range of gains it is capable of producing. No simulations at all — just the numbers in the saved model files. It measures the range of a dial rather than watching anyone turn it.

This ran first because it is the cheap test that could have stopped everything: a dial with no range would have made the rest pointless.

Found
The narrowest range anywhere is 7.95 — one unit's multiplier could differ by roughly ±5 between two situations. Zero would have meant "physically incapable of varying". Nothing came close.
Also
Across all 60 measurements the range is smallest at the first checkpoint and largest at the last, growing about 1.6× over training. The modulator's capability only ever expands.
Holds up?
Yes — that expansion is measured within each agent, so it does not depend on having only one agent per configuration.

A pleasant surprise in the derivation: the headline number is exact rather than an upper estimate. The memory cell's arithmetic guarantees its internal state can never leave a fixed range, which pins the gain's swing precisely. Analysis 02 later confirmed this by measurement — the state reached that limit and never exceeded it, in all 30 agents.

02

Does it actually vary with context?

done

Method, in plain terms. Run each trained agent through 128 episodes and record every gain and offset it emits. Then split that variation into two parts: how much the numbers differ between units — a fixed re-tuning, where unit 5 always gets 0.3 and unit 6 always gets 0.9 — versus how much they differ over time, which is genuine responsiveness to what is happening.

The second share is what this page calls the contextual fraction. A fixed re-tuning is not nothing, but it is something the main network could have learned in its own weights without any modulator — mathematically, it can be folded in and cancelled out.

Found
Only about 15% of the gain's variation is contextual. The other 85% is fixed re-tuning.
Sharpest
Modulators allowed to read only the body signals — how full the agent is, and how much pain it currently feels — are 2–4× less responsive at every site, 15 of 15 with no exceptions. At the encoder, 97% of their variation is fixed.
Holds up?
That ordering repeats within every site, which is what makes it survive having one agent per configuration.

Against a published comparison. The original FiLM paper reports 36% of its gains going negative and 76% of its offsets; ours are 16.8% and 68.5%. Offsets match closely; negative gains are about half as common. And where their modulation shows a sharp spike of gains at zero — features switched off outright — ours has none. Theirs switches features off; ours turns them down, with 77% of gains sitting below 1.

The counterweight, which is real. Hunger and pain change slowly. A modulator tracking them varies slowly by construction, so low variation is not proof of no effect — which is exactly what analysis 03 was built to settle.

An unexpected structural result. About a third of units at every site genuinely take both signs during an episode, and almost none is permanently negative. That distinction matters: a permanently negative gain is something the layer's own weights could have absorbed, whereas a unit that flips a feature's sign in some situations and not others is doing something no fixed setting can imitate.

03

Does that variation do any work?

done

Method, in plain terms. Take a trained agent and replay it on the same episodes twice — once normally, once with the modulator's output frozen at its own average. Frozen means it still adjusts the network, but identically in every situation, ignoring context entirely. If the agent does just as well frozen, the responsiveness was decoration.

Two design choices carry the result. Episodes are paired — the same starting conditions in both conditions — so the comparison is like with like rather than two averages that might differ for unrelated reasons. And the gain and offset are frozen separately, because an earlier paper found freezing the gain cost 65 points of accuracy while freezing the offset cost 1; freezing both at once would have hidden which one mattered.

Found
Freezing costs 47–180 survival steps of about 200, and changes the outcome in 33–84% of episodes.
Shape
Lopsided, not uniform. At the actor site the typical episode loses 10 steps, but the worst 5% lose 480. Freezing usually costs a little and occasionally costs the whole episode.
Holds up?
Yes — it compares an agent against itself on identical episodes, so it does not lean on having several agents per configuration. The lopsidedness is only visible because the episodes are paired.

A check that makes the rest trustworthy. Freezing the modulation at the critic site changed nothing whatsoever — 0.000 steps, in 0 of 128 episodes. That is exactly right by construction, because the critic estimates how good a situation is and does not choose the action. It works as a positive control: a test whose answer is known in advance, run to check the apparatus. Any accidental randomness in the replay machinery would have shown up there as noise. It didn't.

The result worth publishing

The original FiLM paper found the gain and the offset wildly unequal in importance — freezing the gain cost 65 accuracy points, freezing the offset cost 1 — and that asymmetry has since been treated as a property of this kind of modulation. It is not. It is a property of where the modulation is applied.

Change in survival steps when that signal is frozen, averaged over both training recipes. Negative means freezing made the agent worse. Live agents survive about 190–220 steps, so −123 is a large loss and −14 is a small one. The +11 is a genuine small improvement, not a typo.

And the pattern was predicted before it was measured

Analysis 02 found that at the encoder the offset carries more of the responsiveness than the gain — the reverse of the actor. That yielded a prediction that could have failed: if the published gain-dominates pattern transfers here, it should transfer least at the encoder.

Ranking all eight arms by the analysis-02 measure against the analysis-03 result gives a rank correlation of 0.643 — a measure running from 0 (no relationship) to 1 (perfect agreement in ordering) — with both extremes called correctly.

Two independent measurements agreeing on an ordering nobody had proposed: one passive, simply watching what the modulator emits, the other interventional, switching it off and seeing what breaks. The single miss is the encoder under one of the two training recipes, where the gain came out marginally larger than predicted.

What this does not say

It does not say the modulator helps

Freezing at the average is mathematically the same as deleting the modulator and folding its constants into the layer it was adjusting. So this shows the variation is used within an agent that has a modulator. Whether agents with a modulator beat agents without one is a different comparison — and that is the one that came back with no difference.

Both findings are correct about what they measured, and they are not in conflict.

The literature's warning is untested here, not refuted

The papers that report a benefit from neuromodulation report it only in settings where the agent faces genuinely different tasks and must work out which one it is in. Ours faces one task family. That warning is about an advantage over an unmodulated agent; everything on this page is measured within a single agent, so none of it bears on the warning either way.

One observation deliberately left uninterpreted

Every frozen agent ends up worse than the agents trained without a modulator at all. That is consistent with the main network having grown dependent on a varying gain — but comparing across differently-trained agents at one agent per configuration is exactly the comparison this project's own bug registry warns against. Named, not concluded.

A caution that turned out to be the story

This page warned from the start that a null result from a coarse instrument is not a null — citing a study whose population-level measure found nothing in a condition where their per-unit measure found the structure intact.

That is what happened here. The behavioural comparison is the coarsest instrument available: it asks whether the whole agent visibly acts differently. It found nothing. A within-agent intervention on the very same runs finds an effect worth 47–180 survival steps. The behavioural null remains a fact about behaviour — it was never evidence that nothing was happening inside.

Still open

The cheapest remaining analysis is the most informative. Analysis 03 was run only on modulators that read everything the agent senses. Analysis 02 says the body-signal-only modulators are 2–4× less responsive — so freezing those should cost far less. If it costs nothing, the whole finding localises to modulators reading the outside world, which speaks directly to this project's interest in body signals.

  • The freeze test on the body-signal and external-signal modulators. Same code, same episodes, roughly the same cost as what has already run. Highest value per unit of effort by a wide margin.
  • How many units are still active after the adjustment is applied. A gain near zero combined with a strongly negative offset could mean a unit is switched off permanently — and a unit that is off in every situation can never recover, because it produces nothing for the learning process to act on. Nothing currently recorded can tell that apart from a harmless turning-down.
  • A per-unit test of what the network encodes about the body. Fit a small model per unit predicting its activity from hunger and injury together, and compare modulated against unmodulated agents.

A blocker that affects all future re-analysis

The current code can no longer load these 32 agents at all. A newer feature made one of its configuration keys mandatory, and files saved before that feature existed do not have it. Analysis 03 worked around this by running in an isolated copy of the code from before the change, verified to produce numbers identical to the earlier analysis — but every future re-analysis meets the same wall.

It was deliberately not worked around by quietly supplying the missing value, which would be exactly the kind of silent default this project forbids. The choice is between a documented compatibility path for older saved files, or a standing instruction to analyse these agents at a pinned version. That is an engineering decision.

Why this was worth doing at all

A survey of 31 papers in this project's library whose own mechanism is this kind of modulation — or a network that generates another network's weights — found that almost nobody looks inside.

Every paper that opens the modulated network is from 2016–2021, plus one 2023 outlier. The 2024–2026 wave of robot-policy papers — ten of them, using the same operator — inspects nothing internal at all.

The standing counterweight

Both neuromodulation papers reviewed report their benefit only where context matters for the reward. One states outright that its advantage vanishes when the different tasks can be solved with similar internal representations — and its authors ran their own representational analysis on their own null results and found no advantage there either.

A single-task-family setting is the regime where this literature reports no benefit, and ours is a single task family. Nothing on this page tests that claim. It predicts that the move which would make the modulator matter is an environment where context has to matter — not a finer instrument.
