A Modulator That Barely Varies

Sixty-four agents, four grids, two sensory settings. Adding a neuromodulator changes none of the ways this agent's behaviour depends on its internal state — and the modulator's own output says why.

PURPOSE

The agent in this project lives in a 10×10 grid world. It must eat or starve, predators hunt it, and it can hide in a bush. At the start of every episode the environment hands it an injury drawn at random from 0 to 100 that it did nothing to earn. It has no sensor for that number — only a delayed, smoothed trace of it on an interoceptive channel. Because the injury is assigned before the agent acts, any behaviour that tracks it is caused by it. That makes this world a clean place to ask how much of an animal's behaviour depends on its own internal state.

A neuromodulator here is a small network that reads what the agent senses and emits, at every step, a per-unit gain and offset applied to one of the main network's layers — the FiLM arrangement. The hope behind it is that an agent with such a mechanism will let its internal state shape its behaviour more than an agent without one.

This page tests that. It compares an unmodulated control against fifteen modulated variants — five places the modulator can act, crossed with three things it can be allowed to read — and it does so four times over, under two return estimators and at two settings of the agent's sense of smell.

What it finds

The modulator moves nothing that was measured. Across three behaviour measures and all four grids, the unmodulated control sits inside the spread of the fifteen modulated cells every time — twelve comparisons, twelve times inside.

And the modulator's own output explains that. Only 8–15% of its gain varies with what the agent is sensing; the rest is a fixed per-unit rescaling that a plain weight matrix could have absorbed during training. There was very little context-dependence in the signal for a behaviour measure to find.

What does move behaviour is the sense of smell. Widening the agent's olfactory field reverses the sign of its injury response — in the window where the injury is still largely intact.

01The four grids

Every grid is the same sixteen cells. One is t1none — the unmodulated control. The other fifteen are five sites — the encoder, the recurrent memory, the actor, the critic, or all four at once — crossed with three input slices, which control what the modulator is allowed to read:

body only
satiation and the interoceptive nociception channel — two numbers. This is the slice that can see the injury signal at all.
world only
exteroceptive nociception, olfaction, collision and vision.
everything
the whole observation.

That grid was then trained four times: under two return estimators (MC, plain Monte-Carlo returns, and GAE, normalised generalised advantage estimation) at each of two settings of the olfactory sensor:

range 0
one omnidirectional sample. The agent smells everything on the grid but cannot tell which direction any of it comes from. Observation width 27.
range 1
a five-cell diamond. Comparing those five readings is what turns a whiff into a direction. Observation width 47.

Sixty-four runs in total. Each was then replayed over 1,000,000 fresh worlds, and — this is what makes the comparison a comparison — every run saw the same million worlds, in the same order, from the same seed base. Episode i presents the same food, the same predators and the same starting injury to every agent. That was verified against the environment's own per-episode dice-rolls rather than assumed from matching configuration.

02Does the modulator change how much an injury matters?

The most direct question. Sort every episode by the injury the environment dealt at step zero, into four equal quarters, and ask how much of its first 25 steps the agent spent hidden in a bush. The slope is the heaviest quarter minus the lightest, in percentage points.

03Is that measurement trustworthy?

The claim above is worth attacking, because this project has already been caught by this exact measurement. The sensor-ladder study found that the same contrast changes its answer twice under nothing but a change of window and variable. So the same three readings are taken here, of all four grids.

A claim on this page was narrowed by this figure

An earlier draft of Figure 1's conclusion said the sense of smell sets the sign of the injury response, full stop. Panel B shows that is true only in the window where the assigned injury is still largely intact. Over a whole life, every grid is negative. The narrower statement is the one this page makes.

04Does the modulator shift what counts as a threat?

Hiding more when injured is ordinary caution, and Figure 1 already shows it. Hypervigilance is a stronger and more specific claim: that being injured shifts the agent's criterion, so an ambiguous, harmless cue starts driving the defence a real threat does. A rabbit in this world cannot hurt the agent — hiding from one is a false alarm by construction — so the test is whether an injury raises the rabbit response by more than it raises the predator response. If both rise equally the agent has simply become more careful, which is not the claim.

05Why nothing moved: the modulator barely varies

Three measures finding nothing invites an obvious objection — that the measures are too blunt. This last figure answers it from the other side, by looking at what the modulator emits rather than at what the agent does.

A FiLM modulator's gain varies in two ways at once. It varies across units — unit 7 is always scaled differently from unit 40 — and it varies across time within a unit, because the agent senses something different from one step to the next. Only the second is modulation in any interesting sense. The first is a fixed reparameterisation that a plain weight matrix could have absorbed during training. The variance splits cleanly between the two, and the fraction belonging to the second is the contextual fraction.

06What is settled, and what is not

SettledStill open
The unmodulated control sits inside the modulated spread in all twelve grid × measure combinations. No site, and no input slice, moves it out. Whether a modulator built differently — a different architecture, a different loss, an explicit pressure toward context-dependence — would behave differently. This page tests the modulator that was built, not the idea.
The contextual fraction is 0.08–0.15 in every grid, which accounts for the three behavioural nulls rather than merely sitting beside them. Why it is so low. Nothing here distinguishes a modulator that could not become contextual from one that had no reason to.
The sense of smell reverses the sign of the injury response in the first 25 steps, in all 64 runs, under both return estimators. What that reversal is. This page measures it; it does not explain why a directional nose should turn an injury from a reason to forage into a reason to hide.

07Limitations

  1. One seed per cell. Every modulated cell is a single training run. Two runs of the same configuration with different seeds land in different places, so a single run describes one agent, not a configuration. The two range-0 grids each carry five unmodulated reference seeds, and those five span most of the range their fifteen modulated cells span — which is the clearest evidence on this page that the modulated spread is largely seed noise. The two range-1 grids have one control run each and no such band, so every comparison there is one run against one run.
  2. Nothing here was pre-registered. The grid was built to ask whether the modulator's input site matters. The comparisons on this page were chosen after seeing that it did not.
  3. The behaviour measures and the mechanism measure use different episodes. Figures 1–3 read 1,000,000 episodes per run from the trajectory store. Figure 4 reads 128 episodes from a separate replay, because the modulator's output is not in the store. They share a seed base, but they are not the same sample.
  4. Two runs of the GAE range-1 grid were retrained. They died partway through their first attempt on a node with another tenant, and were relaunched and retrained to the full budget before being collected. Their superseded directories are kept, unused, under results/_superseded/ and are read by nothing on this page.
