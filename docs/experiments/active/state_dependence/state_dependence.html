The World, Not the Brain

We spent months asking whether a neuromodulator makes an agent's behaviour depend more on the state of its own body. It doesn't, measurably. What does — by a factor of five — is changing the world it lives in.

01 What this page is about

An agent lives in a small grid world. It gets hungry, it gets wounded, predators hunt it, and bushes let it hide. The idea under test is a neuromodulator: a small extra network that reads the agent's internal state — how hurt it is, how hungry — and uses that to rescale the signals flowing through the rest of its brain. It is loosely modelled on what chemicals like noradrenaline do in a real nervous system.

The prediction that follows is specific, and it is not "the modulated agent behaves differently". It is that the modulated agent's behaviour should depend more on how its body feels. So the measure is a difference of differences:

The measure, in one line

state span = % of steps hiding when badly wounded − % when unhurt, with no threat present

Big means behaviour tracks the body. Zero means the body makes no difference to what the agent does.

Three findings, and the first one is a correction to our own earlier reading.

  1. The obvious way to measure this gives the wrong answer, and gives it confidently — a flat number across six very different agents that turns out to be a property of the environment rather than of any of them.
  2. Measured properly, state-dependence rises five-fold across three versions of the world — and the neuromodulator moves it by less than the difference between two runs of the same agent with different random seeds.
  3. The modulator is not idle. But about nine tenths of what it does is a fixed rescaling that never changes, and only the remaining tenth tracks the body at all.

02 The trap: a number that is flat for the wrong reason

An agent's injury level is not handed to it — it is earned, by being bitten. And being bitten means a predator was on top of it, which is itself the thing that drove it into a bush. So if you measure "how much does this agent hide when wounded" over ordinary episodes, a large part of what you measure is not the agent's policy at all. It is the shape of a predator encounter, which is the same in every world and for every agent.

The environment provides the way out. In some episodes the agent is handed a wound at the start, drawn at random, before it has done anything. Behaviour that tracks that number cannot have caused it.

03 What actually moves it: the world

Read properly, the same measure separates three versions of the world very clearly. Each rung is a real change that was made for its own reasons, months apart.

The comparison that matters

World changes: +3.7 points (vision) and +12.2 points (cover heals) — 2.9 and 9.8 times the run-to-run noise.
Neuromodulator: −1.7, −0.1, +0.2 points across the three worlds — 1.4, 0.1 and 0.2 times the same noise, in inconsistent directions.

04 Is the modulator even running?

A null result always has a boring explanation waiting: perhaps the extra network did nothing at all, in which case the experiment says nothing about the idea. That can be checked directly, by replaying trained agents and recording every number the modulator emits.

It is not idle. But what it does divides in two, and only one half can possibly produce state-dependent behaviour. Some of its output is a constant per channel — this feature always amplified, that one always damped, whatever is happening. That is a learned weight wearing a different hat. The rest varies moment to moment as the body's state changes, and that part is the entire mechanism the design rests on.

05 The result we had not reported at all

The tool that computes all of this names a different measure as its headline, and our earlier analysis omitted it. Instead of asking where the agent is, it asks what the agent decides: among the moments when it stands in the open and chooses to move, how often does the move take it into cover? That matters because a wounded agent mostly stops moving in order to heal, and whether stopping counts as "hiding" depends only on whether it happened to halt on a bush. An agent that freezes drops out of this measure instead of inflating it.

07 What we would still not claim

The binding limit

One training seed per cell. Every bar on this page is one run. The error bars are borrowed from a five-seed measurement in a different, simpler world, so they are an estimate of the right quantity rather than a measurement of it here. A modulator effect smaller than about a point could not be detected by this design at all.

  • Everything is read at the final saved checkpoint. A companion analysis this week showed that a behaviour measure read off the last checkpoint can differ from the average of the last ten by enough to reverse a conclusion. A million episodes removes sampling noise, not that drift.
  • The blind-to-sighted step changed two things, not one — vision, and whether a predator could walk into the hiding bush. No difference across that step can be attributed to either alone.
  • The causal restriction is not perfectly clean. Episodes in the most-wounded quarter survive to be counted slightly less often than the least-wounded, and by different margins in different worlds, so survivors are mildly selected toward hiders.
  • "The modulator does nothing" is not established — only that its effect on this measure, in these worlds, is smaller than the difference between two random seeds.

08 How to reproduce this

The measure is scripts/analysis/context_dependence.py, run over the trajectory stores under results/trajectories_*; its outputs are the JSON files in results/analysis/basicq2_w1/, one per run, each carrying both panels. The five-seed noise estimate is the context_seedscale directory, computed from five seeds of one unmodulated agent. The modulator's gain decomposition comes from scripts/analysis/nmn/run_mod_distribution.py. Each figure is one script under scripts/analysis/studies/state_dependence/ and emits its own data-accounting file beside its image.

Departures from the House Style Sheet: the chrome accent and warning hues are moved off the figure palette, which the sheet requires when figures spend colours on data categories; headings are set in Pretendard and code in the reader's system monospace, because the sheet links its IBM Plex families from a font host a published page cannot reach; and wide tables sit in horizontal scroll boxes with an overflow cue, which is the sheet's own mechanism.
