Grid-world environment · parameter reference

Hiding Factor Atlas

In this project an agent lives on a 10×10 grid, and one of the things it does is stand inside a bush — a behaviour the project measures as bush hiding: the share of an episode's steps spent in a bush. Several studies have asked what makes it do that more or less. This page is the inventory behind that question: every setting the environment has, what it actually does, whether it changes from one episode to the next, and whether anyone has yet tested it as a driver of hiding.

The reason the question is answerable at all is that this world rerolls its own contents before every episode — how many predators appear, how far each can see, how many bushes exist, how hurt and how hungry the agent wakes up. Those rolls are made before the agent acts and are independent of it, so their effect on behaviour is causally identified: it is a randomised experiment the environment runs on itself, a million times over. Settings that don't reroll are fixed by the config file, and testing one of those means training a new agent.

Where the evidence stands

Each parameter below carries one of four states. The counts are computed from the catalogue itself, so they cannot drift away from it.

Three ways a setting can vary

Every entry in the catalogue is tagged with one of these. The tag is the single most important thing about a parameter, because it decides what it costs to study: a value the world rerolls is free to analyse from data already collected, while a value fixed in the config file cannot be studied without training another agent.

ep
Redrawn at every reset, independently of the agent. Causally identified, and already recorded in the per-episode table of the trajectory store.
event
Redrawn each time the thing happens — every collision, every pounce. Recorded in the per-step table.
derived
Not a draw at all, but computable from recorded positions. Free, and almost entirely unexplored.
within
Changes over the course of an episode as a consequence of what happens in it. Associational, not causal.
fixed
Constant in this world. Studying it means a different config, and therefore a new training run.

    Where I would look first

    Three seams stand out, ranked by what they cost. The first two need no new training and no new data collection — everything they need is already in the million-episode store.

    Spatial arrangement free — data already collected

    Every factor tested so far is a count or a trait: how many bushes, how far a predator sees. Nothing tests arrangement. Ten bushes clustered in one corner and ten spread evenly are the same number and a completely different world for an animal deciding whether cover is reachable. The published study already shows the strongest hint of this — spawning next to a bush gives far more hiding than spawning five cells away — and that is one crude summary of a geometry that is fully recorded and otherwise unused. The sharpest versions are the ones where cover is nominally available but actually is not: a predator standing between the agent and its nearest bush, or a bush sitting on top of a buried ambush.

    How hard each hit lands free — data already collected

    A predator's damage is drawn from [15, 120] on every collision — an eightfold range — and no analysis so far distinguishes a graze from a near-fatal blow. That is a randomised treatment applied repeatedly inside each episode, sitting in the damage column of every step file, unexamined. The same is true of whether a pounce connected or missed, which is a coin flip the world makes on the agent's behalf.

    The three chase traits nobody has switched on needs a new training run

    The config schema declares five predator traits as per-episode distributional fields, but in this entire config line only two are ever given a real range — detection_range and max_stamina. Stamina recovery, hunt threshold and chase persistence are written as degenerate [x, x] in every live config, so the sampling machinery runs each episode and returns a constant. Real ranges for them exist only in three archived hypervigilance configs. They are three causally-identified factors the environment is already built to randomise and nobody currently turns on — cheap to enable, but they change the training world, so they cost a run.

    Where this came from

    Every value in the catalogue was read from these files. The reference world is the arm of the resting-bonus sweep where resting earns no extra healing, which is the agent the published hiding study analysed.
