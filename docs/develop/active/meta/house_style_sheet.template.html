House Style Sheet

One set of fonts, colours, numbers and boxes, so that every page this project publishes reads as the same body of work.

PURPOSE

This project publishes its plans and results as web pages. Until now each page picked its own look, so a reader moving from one to the next had to learn a new set of colours and labels each time. This sheet fixes one default. A new page starts from here, and departs from it only for a reason it can state.

Most of the look is taken from one page that worked: the Thermoregulation design plan — its colours, its condensed headings, its two-digit section numbers, its boxes, glossaries and step lists. Two things are changed or added. Running text is set in Pretendard instead of a serif, and there is a tab component the Thermoregulation page never had.

The rules for charts come from a separate study of how a published research page draws its figures (§10). The chart on this page is drawn by the same Python module every project figure can use, so the sheet shows the style working rather than describing it.

01 Type

Three faces, one job each. Pretendard carries everything a reader reads through. IBM Plex Sans Condensed carries everything a reader scans for — titles, section numbers, table headers, eyebrow labels. IBM Plex Mono carries anything that has to be typed exactly: config keys, file paths, glossary terms, numbers in columns.

Pretendard · running text · 16.5 px / 1.68

The agent's temperature drifts toward whatever cell it is standing on, so away from the fire it cools steadily; near the fire it recovers. Food grows away from the fire, so every meal is a trip out into the cold and back — semibold for the one phrase that carries the sentence.

Pretendard has no italic. Emphasis in italics is therefore a slanted Regular drawn by the browser, which is legible but not beautiful. Prefer semibold for weight and save italics for titles and foreign terms.

02 Colour

Neutrals do almost all the work. The five greys lean slightly green rather than being pure grey, and the ink leans slightly blue. The four hues are used sparingly, and each has a role.

#fbfbfa--ground · page
#f1f2f0--surface · boxes, code
#e9ebe8--sunk · code blocks
#dcdedb--line · row rules
#c9cdc9--rule · header rules
#16181d--ink · text
#4e545e--ink-2 · captions
#6e747e--ink-3 · labels
#2a78d6--accent · series 1
#eb6834--warn · series 2
#0f7a55--ok · series 3
#b02b2b--danger · series 4
#e8f0fc--pick · chosen row

One hue, one meaning, per page

Each hue has two possible jobs: chrome (a section number, a box border, a glossary term) and data (a line in a chart). The two are separate tokens with the same default values — --accent and --series-1 are both blue.

Rule · format register F11 amendment

If a page's figure spends a hue on a category, nothing else on that page may use that hue. Say blue means “agent with the modulator” in Figure 2. Then the section numbers and glossary terms on that page must stop being blue. Override --accent and --accent-text to var(--ink) on that page and leave the figure alone. This sheet is the one exception it allows: its specimen chart encodes no category at all — its lines are only “series 1” and “series 2”.

Two smaller notes. Blue as text — links, section numbers, glossary terms — uses --accent-text #1f62b4, because #2a78d6 is only 4.3 : 1 on the page ground; borders and chart lines keep #2a78d6. --ink-3 is #6e747e, a shade darker than the Thermoregulation page's #767c86, and is used only on the page ground, where it clears 4.5 : 1; on a tinted box, labels use --ink-2. And green against red is a poor pair for a reader with red-green colour deficiency. A figure that needs series 3 and 4 together should also vary line style or marker.

03 Numbering and labels

A section number is two digits in condensed semibold, blue, set on the same baseline as the title and 14 px before it. The page cites sections as §3, never “section three” or “above”.

01, 02 …
Body sections. Number them when a reader will cite or jump to a section by number — a plan, a reference, a long analysis. A four-section note does not need them.
PURPOSE
The entry-point section, labelled with a word in the number's slot. It is not counted, so 01 is the first section of substance.
STAGE 0
Steps that really happen in order (§8). Grey, not blue — the number is part of the step, not a place to jump to.
eyebrow
A small uppercase label above a title or inside a box, saying what kind of thing follows: “Scale warning”, “Consequence for the config”.
Figure J
Figures are named in the caption's first bold phrase, and the text refers to them by that name.

04 Boxes

A box is a tinted block with a coloured left border. The border colour says what kind of statement it holds. Use at most one or two per section. A page where every paragraph is boxed has no boxes.

Note · .callout

A finding or definition the reader should carry forward. EVAAA's shipped smoothing value is for a 100×100 grid; ours is 10×10.

Warning · .callout.warn

Something that will go wrong if ignored, or a correction kept on the record. An earlier version of this measurement used the wrong ground truth; the conclusion survived, the margin shrank.

Decision · .callout.pick

What the page recommends, or what was chosen. Use the diamond neighbourhood at thermal_grid_range: 1.

Hazard · .callout.danger

Loss of data or of comparability. Once temperature enters the reward, every earlier run becomes incomparable unless the change is gated.

05 Tabs

Tabs hold alternatives the reader compares — two configurations, one figure at several settings, the same table for each agent. Tabs must not hide the argument. A reader who never clicks should still get the conclusion, so the first tab is the one the page recommends, and anything essential is repeated outside the tabs.

A lethal world with one refuge. The agent must return to the fire before it freezes, so it needs to remember where the fire is.

Labels are condensed uppercase, like table headers; the chosen tab takes the ink colour and its 2 px underline turns blue. Arrow keys move between tabs, Home and End jump to the ends, and each panel is reachable with Tab. Hidden panels use the hidden attribute, never an author display rule (register F14). They are also never painted in a screenshot, so a format review has to open each tab (F17, F19).

06 Glossaries

A glossary is a two-column list: the term in blue mono on the left, a plain-English definition on the right. Use it wherever a page introduces words a fresh reader will not know. It also works for small parameter lists where each value needs a sentence. On a phone the two columns stack.

survival steps
How long an agent lives in an episode, counted in environment steps. This project measures performance this way, never by cumulative reward.
Interoceptive Nociception
The observation channel that reports injury to the agent. The injury level itself stays hidden; the agent only receives this signal.
thermoceptor
The sense that reads the temperature of the cells around the agent, relative to its own body temperature.
bush dwell
Time the agent spends inside a bush, where predators cannot see it.

07 Tables

Rules between rows only — no vertical lines, no zebra stripes. Headers are condensed uppercase in the label grey. Numeric columns are right-aligned in mono, so digits line up by place value. The recommended row takes the pick tint, and its first cell turns blue.

08 Steps and open questions

Two list components. Steps are for work that really happens in order. Open questions are for what the page has not decided — each one a bold question followed by why it matters.

STAGE 0
Parity harness, before any change
Snapshot observation, reward and drive for a sample of configs. Every later stage runs against it.
STAGE 1
The field and the campfire object
No observation change, no body change. Parity must hold.
STAGE 2
Body temperature
Not observable and not in the drive yet.
One fire or several?
Several fires turn a leash into a network, and let food sit between refuges.
Should creatures carry heat?
A warm predator becomes detectable at range — a second detection channel, or an accidental radar.

09 Code and equations

Inline code is mono on the surface tint. A block of code or an equation sits in a sunk panel with a grey left border. Comments are label grey, and the one term the reader should notice is blue. Equations are written out in text, not typeset, so they stay copyable.

10 Figures

A figure on an artifact page is never drawn by the page. No chart is written as inline SVG, CSS bars or a canvas in the HTML. Every figure comes from a Python script, which saves it as a file; the page builder embeds that file. The same script can then be re-run to rebuild the figure, imported into a notebook, or pointed at new data — and the vector copy goes straight into a paper. A chart that exists only inside a web page can do none of that (guide §2.7).

STEP 1
One script per figure
scripts/analysis/.../<stem>.py computes the numbers and draws one figure. It calls house.apply() first and sets no colour, font size or gridline itself (guide §5).
STEP 2
The script writes files, and checks them
house.save() writes <stem>.svg, .pdf and .png, refuses a label under the 9 px floor or ink touching an edge, and the script writes <stem>.data.txt — how much data it used (guide §11b).
STEP 3
The builder embeds; it never draws
Each <img data-fig="<stem>"> in the template is filled with that PNG. The build fails on a figure with no script, no file or no data statement, and on any <svg> or <canvas> inside a <figure>.
STEP 4
The reader can open it full size
Clicking a figure opens it fitted to the window; a second click shows its real pixels. Enter or Space opens it from the keyboard, Escape closes it (guide §2.6).

The chart rules, in the order they matter

1. The axis spine is deleted, not lightened. What remains of the axis is a set of faint horizontal rules in --line at the labelled values, so the eye reads values off the chart rather than off a frame.

2. Two steps of hierarchy inside the figure. Tick labels are 11 pt in label grey; axis titles are 13 pt semibold in ink. A reader finds out what is plotted before how much.

3. The legend sits below, centred, unboxed. A legend floating over the data is the most common way a figure loses a series.

4. The figure sits on the page ground. Paper is #fbfbfa, not white, so a figure does not read as a separate card.

5. Hue is spent only on data. Everything structural is grey. Series 1 and 2 are blue and orange, the pair that survives the common colour-vision deficiencies.
