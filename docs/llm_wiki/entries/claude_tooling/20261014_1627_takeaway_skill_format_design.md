# /takeaway: take-home box, then a job-shaped table, as a flexible default

## Key conclusion
The user wanted a companion to `/progress`. `/progress` says what has been done; `/takeaway` says what it means. Each design choice came from the user's feedback:
- A 150-word cap was too short, so the cap became ~300 words.
- A wall of prose hid the main point, so the layout became a headline box plus a table.
- The first version only fit analyses, so each kind of job got its own table columns.
- A fixed template forced answers into rows they didn't have, so the layout became a default the agent may change.

## Evidence, measurements, facts
- Design path (2026-10-11), set through `/ask` rounds:
  - format "take-home + why + next", jargon explained inline on first use, scope = the current job;
  - 150 words, then 300 words;
  - the user picked the "Headline box + table" layout;
  - extended to every kind of job;
  - the format made a default.
- Table columns by kind of job:

  | Kind | Columns |
  |---|---|
  | Analysis | What was measured / Result / Compared with / Supports the take-home? |
  | Development or fix | Change / What it does / Checked by / Works? |
  | Bug hunt | Possible cause / Evidence / Verdict |
  | Plan | Step or option / What it involves / Risk or cost / Decision |
  | Training launch | Run / Where / State / Check |
  | Other | Item / Finding / Verdict |

- Facts are re-checked before printing. What gets checked depends on the kind of job: the owning doc or results table for an analysis, git and real test output for development, the plan doc and its reviewer verdict for a plan, live process and GPU state for a launch. A fact that can't be confirmed is dropped or marked "(not yet checked)".
- Jargon rule: plain words first, with the term in parentheses on first use, for example "extra time hiding in a bush when hurt (injury effect)". No run IDs, SHAs, paths or bare shorthand.
- Commits: first version 46549cfd, box + table layout 5f6af25f. The all-jobs, flexible-format version was written during the NAS rebuild hold and was not yet committed when this note was captured.

## Decisions and actions
- Skill file: `.claude/skills/takeaway/SKILL.md`. It only prints; it writes nothing to the board, diary or git.
- The take-home box must carry the whole answer on its own; the table holds the 2–6 facts it rests on.
