# Half-factorial repeat seeds: world 6 repeats first

## Key conclusion
In the first tested repeat runs (seed 43), world 6 — predator threat changed (A) plus rocks and traps invisible
(C) — again shows a large injury contrast (how much more an injured agent hides near the harmless rabbit than with
no animal), for both agents. The other early repeats are positive but uncertain. Too few runs to judge any group yet.
