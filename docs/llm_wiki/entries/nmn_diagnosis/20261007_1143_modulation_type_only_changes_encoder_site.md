# modulation.type only changes the encoder site; non-FiLM types start the other sites at 3x gain

## Key conclusion
The three modulation types differ only at the encoder (per-sensor and multimodal layers): FiLM =
ReLU(gamma*x + beta), gamma unbounded, starts at 1; PreActivation = ReLU(sigmoid(z)*x + beta), gain in (0,1);
Multiplicative = ReLU(x)*sigmoid(z), gain in (0,1), no offset. The rnn/actor/critic sites (added by the
September site refactor) always apply z*x + z_add. Their gain heads use bias 1.0 only for FiLM; for any other
type they take percept_bias_init, which is 3.0 in every current config - so a type switch silently starts those
three sites at 3x gain.

## Evidence, measurements, facts
- src/models/recurrent_ppo_network.py ObservationEncoder hierarchical forward: the three type branches (FiLM /
  PreActivation / else Multiplicative); site application z_rnn*x_h + z_rnn_add, z_actor*a_pre + ..., z_critic*c_pre + ...
- src/models/neuromodulator.py: _percept_bias = 1.0 if FiLM else percept_bias_init; _film_pair() uses _percept_bias
  for head_rnn / head_actor / head_critic.
- Unknown type strings fall through to the Multiplicative branch with no error (already recorded in
  [[20260723_1911_rppo_nmn_config_boundary_traps]]).
- No experiment has ever compared types: all September runs are FiLM.

## Decisions and actions
- Not tested yet. A fair type comparison must set percept_bias_init: 1.0 (or use the encoder site only), and
  should whitelist type names.
