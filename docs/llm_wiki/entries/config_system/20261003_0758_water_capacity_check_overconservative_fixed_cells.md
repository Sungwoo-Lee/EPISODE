# Water capacity check rejects fixed-position scenes (over-conservative)

## Key conclusion
The check guarding the silent (0,0) placement fallback (KNOWN_BUGS ~#117) in `src/environment/config_loader.py` requires, for the slot at scan position k, that its area minus the worst pond overlap has at least k+1 cells. Earlier slots in disjoint areas cannot block it, so the bound is too strict: probe scenes that pin bush, campfire and animal spawn to single cells fail at the second item ('1 cells remain for 2 slots') wherever the pond is. The intended fix replaces k with the number of earlier slots whose area intersects this one, which keeps the guarantee and changes validation only, not placement.

## Evidence, measurements, facts
- Failure observed by the developer generating thirst probe scenes on branch bb-water (C7b).
- Training worlds use large random spawn areas, so the bug never triggered there.
