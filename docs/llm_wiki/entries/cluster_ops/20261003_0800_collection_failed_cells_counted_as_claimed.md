# Collection launcher treats failed cells as done; node 114 lacks pyarrow

## Key conclusion
The thirst-task trajectory collection put two cells on node 114, where `import pyarrow` fails in the grid_world_pain env, so both workers died at import. The launcher's relaunch dry run then reported 'finished=18 claimed=18 to-launch=0', because a fail marker still counts as claimed. Writing a spec with only the two failed runs and running it on nodes 106/107 collected them in 43 and 58 minutes.

- Avoid node 114 for trajectory collection until pyarrow is installed there.
