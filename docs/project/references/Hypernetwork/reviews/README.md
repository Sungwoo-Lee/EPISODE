# `Hypernetwork/reviews/` — per-paper reviews

One file per paper, matching the convention `FiLM/reviews/` and
`neuromodulatory_algorithms/reviews/` already use. Created 2026-09-09, when eight papers
were added to this shard for the FiLM-and-hypernetworks-in-RL field review and appending
eight full reviews to the 134 KB master document would have made it unreadable.

The master review at [`../hypernetwork_lit_review.md`](../hypernetwork_lit_review.md) still
covers the original eight papers and carries the cross-paper synthesis. It also carries a
**correction note** for Beck et al.'s Table 2, which had been misread in a way that inverted
the corpus's headline FiLM-versus-hypernetwork claim — read that before quoting any number
from it.

Reviews here were written as two batches and split into per-paper files; each states which
batch it came from in its frontmatter.
