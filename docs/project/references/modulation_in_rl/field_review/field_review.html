Conditioning the Policy

A neural network that has to behave differently in different situations can be told which situation it is in. This is a map of how that is actually done in reinforcement learning — and of how thin the evidence is that it works.

98 papers · 2002–2026 52 run a reinforcement-learning algorithm Compiled 2026-09-09

Start hereWhat this page is

Suppose you are training an agent that must behave one way when it is carrying a heavy box and another way when it is not. You could feed "am I carrying a box" into the network as an extra input and hope it learns to use it. Or you could build a second, smaller network whose only job is to read that fact and re-tune the main network on the fly — turning some of its internal signals up and others down.

That second option is the subject of this page. It has two main forms. In the cheaper one, the side network outputs two numbers per internal unit — a multiplier and an offset — and that is called FiLM, for feature-wise linear modulation. In the more expensive one, the side network outputs the main network's weights outright, and it is called a hypernetwork. They are not rival ideas. FiLM is the special case of a hypernetwork that generates only a scale and a shift, and most of this page is about what sits between them and what that costs.

The page answers five questions, in order: what the operator actually computes; where it sits on a spectrum from "just concatenate the extra input" to "generate every weight"; where in a reinforcement-learning agent it gets injected; what signal it is allowed to read; and — the part that matters most and is least often asked — whether any of it is demonstrated rather than merely described.

The short answer to the last question is that the literature is much thinner than its citation count suggests. Of the 52 reinforcement-learning papers here, 31 run a controlled comparison that isolates what the conditioning contributes (60%), and several of the most-quoted numbers do not survive being checked against the original table. One of them did not survive being checked while this page was being written — see Corrections.

VocabularyThe terms this page uses

Defined here, used freely afterwards. Symbols are given alongside the English so that a paper's notation is recognisable when you meet it.

Modulationalso: conditioning
Changing what a network computes based on some extra signal, by altering the network itself rather than by appending the signal to its input.
FiLMγ β
Feature-wise linear modulation. For each internal channel, multiply by a gain γ and add an offset β, both produced by a small side network reading the conditioning signal. "Feature-wise" means one pair of numbers per channel, not per connection.
Hypernetwork
A network that outputs another network's weights. FiLM is the restricted case in which the only things generated are a per-channel scale and shift.
Conditioning signalz, c
Whatever the side network reads: a task label, a language instruction, an inferred belief about which task this is, measured physical parameters, or the observation itself.
Injection site
Where in the main network the modulation is applied — the perceptual encoder, the shared trunk, the actor, the critic, the world model.
Actor · critic
Two halves of a common reinforcement-learning agent. The actor chooses actions; the critic estimates how good a situation is, and is used to train the actor. Modulating one is a different decision from modulating both.
adaLNAdaLN-Zero
Adaptive layer normalization: the same gain-and-offset operator, folded into a transformer's normalisation layer. "Zero" means the generator's output weights start at zero, so the block begins as an exact identity and the unmodulated model is a point in the modulated model's parameter space.
Concatenation
The baseline this whole literature is arguing with: just glue the conditioning signal onto the input vector. Cheap, and frequently competitive.
Ablation
An experiment that removes or swaps one component while holding everything else fixed, so the component's contribution is isolated. A paper that describes an architecture and reports that it works has not ablated it.
In-distribution · out-of-distribution
Tested on situations drawn from the training range, versus outside it. Several results on this page are ties in-distribution and wins out-of-distribution, so the distinction decides what the paper shows.
Seeds
Independent training runs differing only in random initialisation. Reinforcement learning is noisy enough that a difference measured on one run per configuration is not yet a finding.

Question 1What the operator actually computes

Strip away the naming and the whole family is one line of arithmetic. Take the vector of activations x at some layer. Have a side network read the conditioning signal z and emit two vectors of the same width. Multiply, then add.

FiLM(x) = γ(z) · x + β(z) Where: x is the layer's activations; z is the conditioning signal; γ(z) and β(z) are the gain and offset vectors the side network produces, one entry per channel; the multiplication is element-wise (each channel is scaled by its own number, not by a shared one).

Three properties of that line explain most of the field's behaviour.

It is cheap. The side network's output grows with the number of channels, not with the number of connections. That is the entire economic argument for FiLM over generating weights, and it is why the operator survives at scales where full weight generation is impossible.

The gain does nearly all the work. In the paper that named the family, freezing γ at its training-set mean cost 65.4 points of accuracy; freezing β cost 1.0. About 36% of the learned gains were negative — the operator is not merely "turning things up", it is also inverting and suppressing them. Bounding the gain with a sigmoid, a hyperbolic tangent or an exponential all made things worse, which is why implementations since use an unrestricted signed gain.

It has a natural identity element. If γ = 1 and β = 0 the layer is unchanged. Two independent 2022–2026 robot-policy papers converge on writing it as (1 + γ)·x + β with the generator's last layer initialised to zero, so training begins at exact identity. This is the same fix that the adaLN-Zero convention encodes, and it turns out to matter more than almost any architectural choice on this page.

A distinction worth keeping

Not everything called neuromodulation belongs on this operator. One line of work gates plasticity — a scalar multiplies the weight update, so the network's state changes in weight space and persists. FiLM is stateless: it changes activations for the current forward pass and leaves nothing behind. Grouping the two together is a category error, and the page keeps them apart.

Question 2The spectrum from concatenation to generated weights

FiLM and hypernetworks are two points on one line. Each rung strictly contains the ones above it, and each buys expressiveness with parameters and with a harder optimisation problem.

0 · Concatenation

cost: nothing — the input vector gets wider

Glue the conditioning signal onto the input and let the network sort it out. Not modulation at all, and it is the control every other rung must beat.

Still the default in contextual RL as of 2026; it is what belief-conditioned meta-RL does, and what an AAAI 2026 oral does.
1 · Gain only

cost: one number per channel

Multiply, don't add. When the gain is squashed through a sigmoid into [0,1] the operator can only suppress channels, never amplify or invert them — a real expressive limit, and also a structural immunity to gains blowing up.

Gated-attention language grounding; the neuromodulatory gate in continual-learning architectures.
2 · FiLM — gain and offset

cost: two numbers per channel

The full affine operator, with an unrestricted signed gain. Folded into a normalisation layer it is called adaLN and is the default conditioning primitive of modern robot action heads.

The largest group in this corpus: 12 of the 52 reinforcement-learning papers.
3 · Low-rank and mixture-over-basis

cost: a small matrix, or k weights over k fixed basis matrices

The first rung that genuinely changes the weights rather than the activations, while refusing to pay for all of them. Attention itself lands here: multi-head attention is provably a linear hypernetwork composing a fixed basis, and at one head it degenerates to exactly a scalar gain.

LoRA-style adapters; generated adapter modules inside a policy; dynamic predictive coding.
4 · Full weight generation

cost: the generator's output layer is (hidden × all target weights)

Emit every weight of the target network. Expressive, and structurally capped: at ResNet-50 scale the output layer alone would hold on the order of 109 parameters. Every reinforcement-learning paper here therefore generates a deliberately small target — large primary network, small generated one.

12 of the 52 reinforcement-learning papers, concentrated in meta-RL, continual RL, zero-shot transfer and multi-agent.
The finding that reframes the ladder

Rungs 2 and 4 are usually presented as alternatives. At least one hypernetwork design in this corpus keeps a FiLM-style gain on top of its generated weights — x ← σ((1 + g(z)) · x W(z) + b(z)) — and documents that gain as necessary for stability, not as an addition. On that reading FiLM and hypernetworks are complements, and the question "which one" is less well posed than the literature's framing suggests.

Question 3Where the operator came from

The mechanism was invented three times before it was named once, and the arc is a repeated argument about where the two numbers come from and what they attach to.

2017 · tied to normalisation

Style, then language

The gain and offset live in a normalisation layer. First looked up from a table indexed by a discrete style — 32 painting styles in 0.2% of a network's parameters — then generated from a language encoder, then computed directly from another image's feature statistics.

γ, β ← lookup table

2018 · cut loose

Named, and freed

The family gets a name and, more importantly, gets separated from normalisation by ablation: move the operator past the nonlinearity and accuracy barely changes; remove normalisation entirely and it costs about four points while the mechanism keeps working.

γ, β ← any encoder

2023–2026 · tied back

adaLN, and zero-init

In robot policy learning the operator is folded back into a transformer's normalisation layer, with the generator zero-initialised so the block starts as an identity. The re-coupling is mundane — the affine slot was already there. The zero-init is not.

γ, β ← timestep, zero-init

Question 4Where it goes in an agent

A reinforcement-learning agent has several places conditioning could enter, and the choice is not cosmetic: modulating the actor changes which actions are taken, while modulating the critic changes the training signal that shapes the actor.

Observation encoderTurns pixels or sensor readings into features. Modulated where language or a second sensory stream should reach into perception.
→
Shared trunk / memoryRecurrent core or transformer blocks. Where adaLN sits in modern action heads — often at every block.
ActorChooses the action. The obvious site, and the most common single choice.
CriticEstimates value, and trains the actor. The contested site — see the disagreement below.
World modelPredicts what happens next, in model-based agents. Nearly untouched.

Teal outline marks a site the corpus actually uses. The world model is drawn unmarked because the Dreamer lineage contains essentially no instances of affine modulation inside the latent dynamics; the one paper that appeared to fill the gap turns out to concatenate rather than modulate.

Question 5What the modulator is allowed to read

This is the axis on which the reinforcement-learning literature is most consistent, and the consistency is easy to overstate. The conditioning signals that appear are task identity, language, an inferred belief about the task, measured physical parameters, an algorithmic knob, or a statistic the network computed about itself.

Question 6Does any of it work?

Here the page turns from description to assessment, and the assessment is uncomfortable. Modulation is cited constantly and isolated rarely.

The pattern across those rows — and where it breaks

When the task is easy, the operator does not matter. Every row above that reports an easy condition reports a tie there, and the parameter-matched comparison reports a four-way tie whenever the context is clean and fully relevant. This is the most robust statement on the page, and it is mostly a warning: a comparison run on an easy benchmark will find nothing, whatever the mechanisms.

What separates the arms is contested. Three settings say the moderator is difficulty — a navigation difficulty mode, a clearance shrinking from 3 mm to 2 mm, a per-task difficulty rating. The most controlled study says it is context quality: arms separate when the conditioning signal carries irrelevant dimensions that shift between training and test, which is a claim about the signal rather than about the task. These are not the same hypothesis and no paper tests both.

And multiplicative fusion does not reliably win. It is tempting to read the first two rows as "modulation beats concatenation once things get hard". The parameter-matched study contradicts that directly: where its context is genuinely necessary, its FiLM-style gate scores 85.0 against plain concatenation's 109.0. What won there was generated weights, and removing the generator while keeping the adapter shape made it much worse — so the credit belongs to weight generation, not to the injection pattern. The honest summary is that operator choice matters, and which operator wins is not settled.

Question 7How it breaks

Sorted by what actually failed, rather than by paper.

  • Initialisation, not capacity. A generated-parameter stack under ordinary initialisation can be broken before the first gradient step: the generator emits a flat weight vector with a single output variance, while the target needs per-layer fan-in-appropriate variances, and one variance cannot satisfy several constraints at once. The fix is one line — zero the generator's last-layer weights and draw its bias from the base network's initialiser — and it moves the headline number on the corpus's central benchmark by a factor of six.
  • Operator choice, through the loss surface. In an offline-RL exploration bonus, concatenation produced a bumpy surface with local minima the actor could not descend, even though the bonus itself was perfectly discriminative. FiLM produced a smoother one. The failure was not in what the network could represent but in what the optimiser could follow.
  • Optimiser settings, not architecture. Generated weights need their own learning rate; one continual-RL paper cut its gradient-norm clip by three orders of magnitude to stop explosions. A FiLM arm's hyperparameters are not portable to a hypernetwork arm.
  • Conditioner/observation entanglement — the mechanism story, and its confound. When the generator reads the same signal as the policy it generates, the derivation that lets the generator's Jacobian be pulled out of a covariance term no longer holds, and the reported effect is degradation across environments. But the ablation that shows this changes two things at once: the arm that reads the observation also regenerates its weights every timestep, where the baseline regenerates once per training iteration. Self- conditioning and regeneration frequency are confounded, and a second paper whose generator reads local observations — but re-queries only on events — beats that baseline outright. The mechanism is plausible and the experiment does not isolate it.
  • Regenerating too often. The axis the confound above exposes, and the corpus supports an ordering on it without ever having tested it directly: once per episode is brittle (one paper's single-query arm collapses from 98.5% to 0%), once per event works, and once per timestep is reported as unstable by two papers independently. A third finds per-rollout regeneration scores 0.50 against 0.52 for per-step — i.e. buys nothing — at roughly a tenth of the per-step cost. Nobody has swept frequency with the architecture and conditioner held fixed.
  • Conditional computation, not gain. The 2024–2026 instabilities cluster on mixture-of-experts rather than on modulation: NaN losses, an expert collapsing without producing meaningful actions, three auxiliary losses needed against mode collapse. A co-located FiLM in the same architecture needed none.
  • Gain blow-up is conspicuously absent. No paper in this corpus reports a modulator that worked and then destabilised because its gains grew. Either it does not happen, or it happens and goes unreported — and the field has no name for it. The one instrument that exists is a Lipschitz bound (the product of the modulator's weight-matrix spectral norms), which tracked performance across six configurations in one preprint and comes with a named remedy.

Question 8What is settled and what is not

Reasonably settled
  • The operator is cheap and the gain does most of the work; bounding the gain hurts.
  • Initialisation dominates architecture. Compare arms under matched initialisation or the comparison measures the wrong thing.
  • On an easy task, or with clean and fully-relevant context, every mechanism ties — including plain concatenation. Benchmarks decide comparisons here more than operators do.
  • Hypernetwork advantages show up out-of-distribution, not in-distribution.
  • Concatenating a signal that is constant within an episode is an additive bias — formally FiLM with the gain frozen at 1. So the interesting comparison is never "modulate or not"; it is "gain, or only offset".
  • Full weight generation is structurally capped; the rule is large primary network, small generated one.
Open, or contested
  • Is FiLM beaten by hypernetworks? The one like-for-like meta-RL comparison is not significant. The one parameter-matched contextual-RL comparison puts generated weights above a FiLM-style gate — but also puts plain concatenation above it, which no account of the operator predicts.
  • Which moderator? Task difficulty and context quality are both proposed, by different papers, and no study varies both.
  • Does weight generation degrade gracefully under a noisy conditioning signal? One paper argues it does and never measures it; another measures it and finds the opposite at high noise, with concatenation becoming the more robust choice. Cite the measurement.
  • Many injection sites or one late one? Two documents in this corpus reach opposite conclusions and neither has been reconciled.
  • Is modulating a critic dangerous? One older report says unstable; three newer papers say it helps or is essential — and none engages the older one.
  • Does modulation need a task distribution? An earlier verdict said yes; four later papers show gains with no task distribution at all, with difficulty as the moderator instead.
  • Is grouped modulation — one gain shared across a block — attested? Once, and forced by a symmetry constraint rather than chosen. An independent test finds the constrained form worse where the symmetry only approximately holds.
  • How often should the weights be regenerated? A live axis the field has not named. Two papers reading the same conditioning signal reach opposite conclusions, and the difference between them is query frequency, not architecture.
  • Does modulator capacity matter at all? The corpus's only direct capacity sweep varies an adapter's rank over a 32-fold range and finds the bands heavily overlapping throughout — the paper's own text names a "sweet spot" its figure does not show.
  • Modulation inside a world model. Essentially untried. The apparent precedent concatenates.

CorrectionsClaims changed while writing this

Correction 1 — the FiLM-versus-hypernetwork number

This corpus's only clean comparison of the two mechanisms was recorded as hypernetwork 42.9% versus FiLM 25.5% and used downstream as the evidence that generating all parameters beats generating only a gain and offset. Re-extracted from the paper with coordinate-preserving extraction, the table says something else: 25.5 is a hypernetwork row (under a different initialisation), and FiLM under matched initialisation scores 34.2 ± 15.9. The like-for-like gap is 8.7 points over ten seeds with heavily overlapping intervals, and the ordering reverses on a second benchmark.

The table was misread because it uses a spanning block label — the architecture name sits on its own line above two initialisation rows — and linear text extraction emits a label, then its rows, then the next label, so a row can appear to belong to the block above it. Corrected, the table supports a different and better-evidenced claim: initialisation dominates architecture. The source document has been corrected in place and carries a signed note.

Correction 2 — the historical backbone is not FiLM

Five papers were acquired as the "canonical conditioning-in-RL backbone" on the expectation that they were FiLM's precursors in reinforcement learning. Read in full, none of them uses FiLM. They use soft routing, an attention-mixture over encoders, and one-hot concatenation. They are the alternatives the operator has to beat, not its ancestry — which makes them more useful than expected, and means any claim that FiLM has a long RL pedigree should be dropped.

Correction 3 — "no RL paper reads the observation" is too strong

Stated plainly this is false: 5 do. The defensible claim is a conjunction — no reinforcement-learning paper here reads the raw observation and modulates the same pathway that reads it. Two of the papers that read the observation modulate a different stream, which is a genuinely different design. A further qualification the reinforcement-learning surveys missed entirely: two self-conditioning architectures do exist inside the wider corpus, and both condition on a compressed statistic of the modulated stream — pooled over time, or averaged over the batch — rather than on a full-bandwidth copy.

Correction 4 — two venues I claimed could not be verified from the paper

Papers were acquired for this review on venue evidence taken from an OpenReview record or an author-declared acceptance string on the preprint server. For two of them the held PDF prints "Preprint" and no venue at all, and several others print no venue line either. The external evidence is real and the acceptances are probably real; the point is that this corpus's rule is what the document prints, and by that rule those papers are preprints. Figure 4's right-hand panel applies the strict rule, which is why it shows more preprints than a bibliography would.

MethodHow this page was built

The corpus is 98 distinct papers, assembled from three cross-corpus digests and the per-paper reviews written for the papers acquired for this review. Those 10 source documents contributed 127 table rows, which merge to 98 papers — 28 of them appear in more than one digest, because the reference library files a paper by mechanism while this review files it by question.

Nothing about the corpus is typed into this page. Every count above and every figure is derived from corpus.csv, which is itself parsed from the digests' tables, so a number here traces to a digest row and a digest row traces to a named section of a per-paper review. The classifications — mechanism, venue tier, claim strength, injection site, conditioning signal — are ordered pattern lists in build_corpus.py, written down once rather than decided per paper, and the build prints every same-author-same-year collision so that a merge is a decision rather than an accident.

Two limits worth stating plainly. This is a shelf, not a sample. The library was assembled around a research question centred on FiLM, so the mechanism distribution reflects that history and not the field's. And the venue rule is strict: a tier is what the held PDF prints, so several papers with genuine top-tier acceptances are counted as preprints here because the held copy is the preprint. Both biases are known and neither is corrected for.
